# Los Vengadores — Casco inteligente

Proyecto escolar de un prototipo de casco inteligente basado en ESP32 para detectar impactos y activar una alerta sonora. La comunicación GPS/GSM se documentará como funcional únicamente después de probar el hardware real.

## Estado
- [ ] Integrar y probar sensor de impacto.
- [ ] Integrar botón de alerta o cancelación según el diseño acordado.
- [ ] Integrar buzzer.
- [ ] Probar GPS/GSM si los módulos están disponibles.
- [ ] Compilar el sketch final en Arduino IDE.
- [ ] Adjuntar evidencias de pruebas y revisión.

## Estructura
- `casco_inteligente/`: código del firmware.
- `docs/`: evidencias y documentación del proyecto.

## Importante
Este repositorio contiene una estructura inicial de trabajo. Antes de dar el firmware por terminado, el equipo debe incorporar el sketch real del prototipo y verificarlo con los componentes físicos.

## Flujo de trabajo
1. Crear una rama por tarea o módulo.
2. Hacer commits pequeños con mensajes descriptivos.
3. Abrir un pull request hacia `main`.
4. Revisar los cambios y probar compilación antes de fusionar.
