Detectar el evento de impacto que utilizará el prototipo para iniciar la lógica de alerta.

- Pin GPIO conectado al ESP32.

- Estrategia para evitar falsas detecciones.

## Pruebas requeridas
- Registrar lecturas normales.
- Probar la detección de impactos de forma controlada y segura.
- Documentar umbral y resultados.
- Integrar con el firmware principal y compilar.
