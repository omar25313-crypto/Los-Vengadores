# Lista de evidencias

Marcar cada evidencia cuando se haya tomado realmente:

- [ ] Perfil de GitHub del propietario.
- [ ] Repositorio creado y su visibilidad.
- [ ] Archivo `.gitignore` en el repositorio.
- [ ] Clonado del repositorio en el equipo local.
- [ ] Configuración de nombre y correo de Git.
- [ ] Rama de trabajo creada.
- [ ] Commit y push realizados.
- [ ] Pull request abierto.
- [ ] Revisión y fusión del pull request.
- [ ] Compilación final del proyecto en Arduino IDE.
- [ ] Pruebas del sensor, buzzer, botón y módulos de comunicación disponibles.

No se debe marcar una evidencia hasta contar con la captura o el registro correspondiente.
